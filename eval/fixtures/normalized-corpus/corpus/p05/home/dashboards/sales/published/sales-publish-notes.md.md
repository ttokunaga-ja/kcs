# Sales dashboard 公開メモ — 7月第4週

今週は Daily Pulse の channel filter を整理し、direct / marketplace を同じ比較線に置かないようにした。Harborline Storefront のキャンペーン流入は marketplace 側の計上時刻に影響されるため、朝の値は前日確定分として読んでもらう。



## 変更内容

| 項目 | 内容 |
| --- | --- |
| Net sales | accounting-confirmed のみを表示 |
| Margin | base freight と surcharge を tooltip で分離 |
| Buyer trend | guest checkout を別注記に移動 |

sales lead には、Mosaic の planning view と日次実績を同じ画面で比較しないことを伝えた。前者は意思決定用の仮定、後者は close 後の記録であり、更新リズムが異なる。
