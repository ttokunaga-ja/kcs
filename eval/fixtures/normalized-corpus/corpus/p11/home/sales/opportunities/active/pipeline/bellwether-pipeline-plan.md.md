# Bellwether Health pipeline plan



## Current qualification

Bellwether has a visible operational problem: commercial requests lose ownership as they move between field teams, finance, and compliance. The prospective sponsor wants an auditable first workflow before discussing broader transformation.



## Path to a credible forecast

1. Run the solution workshop with representative request types.
2. Confirm an operating owner, security reviewer, and procurement contact.
3. Present a bounded configuration plan tied to the first workflow.
4. Convert only after Bellwether accepts the scope and internal decision path.



## Forecast hygiene

Keep the opportunity in discovery until the customer names the operational owner and agrees that historical migration is outside the initial phase.
