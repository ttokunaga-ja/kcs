## Review checkpoints

Before normalization, verify that the plate manifest, control observations, and sample receipt refer to the same run label. Confirm that the acquisition workstation export was staged without changing vendor field names.

- Retain blank wells in the original export so that the plate layout can be reviewed later.
- Record a file or receipt mismatch in the run note instead of correcting the vendor file in place.
- Keep the calibration reference with the run packet when the package is prepared for a cross-site discussion.

If the control record is incomplete, pause the analysis handoff and request confirmation from the instrument owner. The review folder should preserve the received material and the resulting decision trail.

# Multiplex assay methods reference



## Reference handling

Separate general literature context from laboratory acceptance language. A paper may describe a useful approach to matrix effects or transfer precision, while the controlled protocol remains the source for local operational thresholds.

For manuscript preparation, use the methods review note to explain that raw exports were retained and plate-level checks occurred before aggregation. Avoid copying temporary workstation settings or staging paths into the narrative methods section.



## Method context

This reference collects the internal terms used when preparing the NovaPlex research-use plasma protein panel. It is intended for analysts who are comparing a current run package with the approved procedure, not as a substitute for the controlled protocol.

The workflow uses matrix-matched standards, plate-level controls, and a retained raw export for each acquisition. The analyst should be able to identify the instrument receipt, plate manifest, and analysis handoff without relying on temporary dashboard labels.



## Recordkeeping

Store the review note with the literature triage and the approved protocol release. When the protocol changes, update the controlled material first and then refresh this reference during the next scheduled methods review.
