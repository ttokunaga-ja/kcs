The consortium requested a focused comparison of the current transfer package before the next cross-site run. This review covers sample identifiers, control treatment, and documentation supplied with the instrument export.

- Replace the retired freezer location in the intake checklist.

- Plate-manifest fields match the current shared data dictionary.
