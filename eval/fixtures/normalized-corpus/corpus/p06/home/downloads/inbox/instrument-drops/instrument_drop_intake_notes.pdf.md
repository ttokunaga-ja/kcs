## Common checks

- Compare the plate count with the workstation receipt before starting any normalization step.
- Confirm the signal unit recorded by the vendor software and retain the original header row.
- Keep blank and control observations visible in the review copy.
- Flag low-volume, missing, or duplicate observations in a separate note rather than removing rows.

The intake review is deliberately narrow. It establishes that the material is complete enough for the analytical team to begin its work; it does not make an interpretation about biological performance.

# Instrument drop intake notes



## Escalation

If a file is incomplete or the manifest is missing, record the issue in the run note and request a fresh export from the instrument owner. Do not repair the vendor file in place, even when the missing item looks straightforward.

For a delayed receipt, keep the staging folder intact and identify the affected package in the team handoff. Once the replacement arrives, add a short confirmation of the version retained for review.



## Receipt workflow

Instrument drops are staged without changing vendor field names. The first review checks file completeness, timestamp order, and the presence of an acquisition receipt. The received copy remains available in the raw-exports folder while a normalized review table is prepared elsewhere.

The analyst should confirm that the plate count matches the workstation receipt and that the same run label appears in the plate manifest. If the vendor archive contains auxiliary files, retain them with the receipt until the analysis handoff has been accepted.



## Closeout

After the analysis package is accepted, retain the original export, receipt, and checksum record with the raw-exports folder. This is the reference point for any later question about data lineage.
