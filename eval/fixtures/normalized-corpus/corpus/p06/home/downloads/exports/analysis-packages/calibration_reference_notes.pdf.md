# Calibration reference notes



## Review convention

Use this note to explain provenance, not to reconstruct a result. It should identify the right record, the timing of the check, and any operational condition that was relevant to the analyst's review.

When an item is ambiguous, return to the original instrument record and document the clarification in the run note. Do not infer a missing calibration result from a downstream graph or a manuscript table.



## Purpose

These notes link an assay run to the relevant mass-spectrometer calibration record. They give an analyst enough orientation to locate the original evidence without treating a convenience note as a replacement for the calibration binder entry.

Calibration evidence should be reviewed before a run package is shared outside the laboratory. The note is most useful when a collaborator or manuscript reviewer needs a concise explanation of the instrument provenance associated with a result package.



## Exception route

If a calibration record cannot be located, hold the external handoff, notify the instrument owner, and retain the incomplete package as received. The follow-up should describe the requested evidence and its eventual disposition.
