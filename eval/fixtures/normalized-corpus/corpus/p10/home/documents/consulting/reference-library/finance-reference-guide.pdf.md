## Start with the source grain

Before a spend bridge is built, record the source period, transaction grain, account mapping, and owner for each extract. A reconciliation that cannot be traced to a client close should be treated as a working hypothesis.



## Decision material

# Useful handover questions

Can a new analyst identify the scenario, source files, owner, refresh date, and open data dependency without searching email or relying on verbal context? If not, add the missing context to the model cover or input notes.

## Separate the drivers

Price, volume, freight, and expedite effects should be visible as distinct drivers. Combining them too early makes it difficult for a sponsor to understand which action changes the result.
