# Financial model input guide



## Purpose

Use this guide when starting a client-facing operating model in the Harbor & Field Advisory template.



## Input conventions

- Place editable assumptions in the Inputs area and use blue text for client-controlled values.
- Keep calculations formula-driven and distinguish linked cells from local calculations.
- Label currency, timing basis, and source owner near each input block.
- Add a short check when a total must reconcile to a client close or operating report.



## Handover checklist

Confirm that a new user can identify the scenario, last refresh date, source extracts, and any assumptions that still need client confirmation.
