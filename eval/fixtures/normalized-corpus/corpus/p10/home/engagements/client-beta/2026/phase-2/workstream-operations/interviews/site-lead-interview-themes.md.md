# Site lead interview themes



## Shared pattern

Depot leads see the same morning pressure points: last-minute route swaps, incomplete exception notes, and delayed confirmation when a vehicle leaves service. The issue is less about one system than about handoffs between dispatch, maintenance, and supervisors.



## What to test next

- Compare the dispatch-plan freeze time with the first reported change by depot.
- Track whether the same exception code is used for staffing and vehicle substitutions.
- Ask supervisors to validate the route handoff sequence against a real morning shift.



## Implication

The operating-model draft should prioritize a visible escalation rhythm and clearer exception ownership before recommending new reporting layers.
