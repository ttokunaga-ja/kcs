# Service model baseline



## Baseline question

Where do planned routes diverge from the executed route, and which handoff creates the largest repeatable delay?



## Current read

The data suggests that early-morning plan changes explain more missed departure windows than in-day traffic disruption. This is consistent with the site interviews, which describe a long approval loop when vehicles are substituted after the dispatch plan is published.



## Analytical guardrails

- Use depot-local time for operational timestamps.
- Treat cancelled routes separately from late departures.
- Keep driver availability and vehicle availability as distinct causes.
