# Northbridge Home Care - discovery scope



## Draft objective

Clarify where intake, scheduling, and referral handoffs create avoidable delay across the Northbridge Home Care network, then identify a practical first wave of operational improvements.



## Proposed work

- Review current intake-to-first-visit flow and existing performance reports.
- Interview a focused set of scheduling, clinical, and referral roles.
- Facilitate one working session to prioritize interventions by impact and feasibility.



## Boundaries

This discovery phase will not select technology vendors or redesign clinical protocols. Any data request will be agreed with the client before access is granted.
