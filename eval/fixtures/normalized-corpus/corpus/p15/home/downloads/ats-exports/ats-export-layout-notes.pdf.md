# 主な列のまとまり

|  列グループ | 確認するときの視点  |
| --- | --- |
|  Requisition context | 案件、担当者、現在の選考段階が一致しているか。  |
|  Candidate routing | 連絡担当と次のアクションが明確か。  |
|  Interview operations | 面談依頼、評価の回収状況、調整上の注意が分かるか。  |
|  Audit fields | 更新日時、操作担当、エクスポートの目的が追えるか。  |



## 受け渡し前の確認

- 宛先に不要な閲覧者が含まれていない。
- 目的に不要な列を添付していない。
- ファイルの保存場所と確認期限を相手に伝えている。
- 作業終了後に一時ファイルの扱いを確認している。



## このメモの用途

採用チームが候補者管理システムから作業用エクスポートを受け取るときの、列の見方と取り扱いを整理したメモです。FY2026 Atlas hiring plan の定例確認では、Kasa Workbench の進捗確認にも使用します。



## 運用上のメモ

定例の数字合わせは、エクスポート単体ではなく案件の最新状態と一緒に確認します。見た目の列順が変わっても、意味づけを推測せず、データ辞書と運用担当の案内を参照してください。

## 基本ルール

- 作業用ファイルは承認済みの共有場所でのみ扱う。
- 個人情報を含む列は、確認目的に必要な範囲だけを開く。
- 編集した列や並び替えは、元データと区別できるように記録する。



# 並べ替えの例

日常の確認では、案件、現在の段階、次の担当、更新日を先に見ます。候補者を比較するための独自の評価列は作らず、評価は承認済みの面談記録に戻って確認します。
