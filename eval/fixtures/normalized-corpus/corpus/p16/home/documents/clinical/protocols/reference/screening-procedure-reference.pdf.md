## 同意説明から検査予約まで

Screening procedure / operational sequence



## 登録前レビューと記録の保管

Study Alpha local reference



### 登録前レビュー

|  確認項目 | 確認の観点  |
| --- | --- |
|  同意記録 | 署名、日付、説明文書の版、説明者の記載  |
|  適格性資料 | 必要な検査が揃い、未確認事項に担当が付いていること  |
|  来院予定 | カレンダーと予約システムの予定が一致していること  |
|  データ入力 | 登録前に必要な EDC 項目の担当者が明確であること  |



### 同意説明

説明は十分な質問時間を確保して行い、急いで署名を求めない。本人が希望する場合は、家族への説明機会と再来院の予定を設定する。説明終了後は、署名日、説明者、使用した文書の版を所定の記録に残す。



### 目的

本書は Study Alpha の候補者を受け付ける際に、同意説明から適格性確認までの担当分担をそろえるための実務用リファレンスである。最終的な医学的判断は治験責任医師が行う。

|  主担当 | Site CRC desk  |
|  参照資料 | 最新の同意説明文書、適格性チェック表、来院カレンダー  |



### 検査予約

1. 来院カレンダーを参照し、必要な診察、採血、画像検査の順序を確認する。
2. 検体ラベルは、予約確定後に研究用識別子で発行する。
3. 画像検査の依頼票には、研究用の手順と匿名化の連絡先を記載する。
4. 予定変更が生じた場合は、予約記録と EDC の担当者に同じ日に連絡する。



### 保管と引き継ぎ

研究用の控えは、施設のアクセス管理下に置き、診療録の原本とは別に扱う。担当交代時は、未完了項目、次の来院予定、問い合わせ先を一覧で引き継ぐ。



### 受付時の確認

- 候補者の相談経路を記録し、診療予約と研究説明の時間を分けて調整する。
- 説明に使う同意文書の版を確認し、旧版を手元に残さない。
- 研究用識別子の発番前に、必要な診療情報が揃っているかを担当医と確認する。

注意: 本書は施設内の手順確認用。承認済み文書を優先する。
