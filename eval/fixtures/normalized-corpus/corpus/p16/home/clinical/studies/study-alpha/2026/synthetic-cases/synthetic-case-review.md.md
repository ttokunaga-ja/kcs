# ORCHID-CKD-201 合成ケース・レビュー

- レビュー日: 2026-07-09
- 対象: `ALPHA-SYN-021`、`ALPHA-SYN-034`、`ALPHA-SYN-052`
- 用途: protocol dry run / EDC 入力フロー確認（ライブ site status ではない）



## 確認方針

このフォルダのケースは、ワークフロー検証のために作成した架空のレコードである。年齢は帯域で表し、住所、連絡先、実在の診療情報、画像識別子は保持しない。ケース ID は再識別に使えない内部トークンとして扱う。



## レビュー結果

| ケース | 主な確認点 | 結果 |
|---|---|---|
| ALPHA-SYN-021 | 同意確認後のスクリーニング入力 | 完了。次来院の予約状態を確認済み |
| ALPHA-SYN-034 | 検査室フィード未着時のキュー移動 | 期待どおり保留キューへ移動 |
| ALPHA-SYN-052 | 補足の同意立会確認（supplemental consent-witness confirmation）が未完了の場合の表示 | 完了扱いにせず investigator delegate へ引き渡す表示を確認 |



## データ品質チェック

- subject token の形式は `ALPHA-SYN-` 接頭辞で統一した。
- すべての日時は演習用のローカル時刻で、実運用の予約情報とは連動しない。
- free-text 欄に氏名、電話番号、医療機関外の識別子がないことを確認した。
- 各ケースの状態遷移は、デモ終了後に削除可能な環境でのみ使用する。



## 次回までの対応

Data Management は、検査未着のケースに表示する理由コードを短くする。CRC Lead は、補足の同意立会確認が必要な場合の記録例を site initiation 資料に追加する。
