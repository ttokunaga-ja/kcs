# EDC データレビューガイド

Study Beta / ORCHID-CKD-202

2026 年 7 月



## エクスポート確認と引き継ぎ

Data review handoff reference



## 確認の進め方と問い合わせ管理

EDC review workflow / Minato site



### エクスポート前の確認

- ファイル名、作成日時、対象範囲を作業記録に残す。
- 共有先に必要な列だけを含め、施設内の直接識別子を持ち出さない。
- 未解決の問い合わせは別紙の管理表で明示し、エクスポート内の値を仮定で補わない。



### 確認順序

1. 来院カレンダーと EDC の来院状態を見比べ、予定変更を先に整理する。
2. 必須項目、日付の整合、選択肢の入力を確認し、記録だけでは判断できない項目を抽出する。
3. 問い合わせは、内容、担当、依頼日、回答予定日を管理表に記載する。
4. 回答後は、入力内容と変更理由が記録に残っていることを確認する。



# 目的

本ガイドは、Minato Medical Center における EDC エクスポートの確認と、サイトからデータレビュー担当への引き継ぎをそろえるための作業資料である。医学的判断やプロトコル解釈は、所定の手順で担当医へ確認する。

|  対象 | Study Beta / ORCHID-CKD-202  |
| --- | --- |
|  利用時点 | 定例データ確認、来院後の入力点検、エクスポート前の照合  |
|  主担当 | Data Review Office と Site CRC desk  |
|  参照物 | EDC listing、来院カレンダー、問い合わせ管理表  |



### 引き継ぎメモ

引き継ぎには、確認済みの範囲、未完了の項目、次の確認予定、担当者の連絡先を簡潔に記載する。データの内容そのものではなく、確認の状態と必要な次の行動を中心に残す。



### 問い合わせの分類

|  区分 | 取り扱い  |
| --- | --- |
|  来院情報 | Site CRC がカレンダーと原記録を確認する  |
|  検査・検体情報 | 担当部署に確認し、必要に応じて責任医師へ連絡する  |
|  画像連携情報 | 受領票と画像担当の記録を確認する  |
|  EDC 操作 | Data Review Office が入力規則を案内する  |

問い合わせは推測で閉じず、根拠となる記録を確認する。

# レビュー前の準備

- 使用する EDC listing の作成日時とデータ辞書の版を記録する。
- 来院カレンダーの変更が EDC の来院状態に反映されているかを確認する。
- 個人を直接特定する情報を、共有用の確認表に転記しない。

この資料は運用上の照合手順を説明するものである。
