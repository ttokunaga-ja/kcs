# 下書き: SSO サインイン後に管理者ポータルから戻される場合

状態: 技術支援レビュー待ち
更新: 2026-07-08
対象: Harborline Workspace の組織管理者



## 先に確認すること

管理者ポータルを開いた直後にサインイン画面へ戻る場合は、まず同じブラウザで別の管理者アカウントに切り替えず、発生時刻を控えてください。組織の SSO 設定を変更する前に、次の項目を確認します。

- 端末の日時が自動設定になっている
- ブラウザで Harborline Workspace のサイトデータを削除したあと、もう一度サインインできる
- 社内プロキシまたはセキュリティ製品が認証ページへの通信を中断していない
- 別のネットワークで同じ操作を行った場合も同様か



## 管理者ができる対処

1. 開いている Harborline Workspace のタブをすべて閉じます。
2. ブラウザのサイトデータから Harborline Workspace に関連する項目を削除します。
3. 新しいウィンドウで組織の通常の SSO 手順からサインインします。
4. 管理者ポータルを開き、メンバー一覧または請求設定まで遷移できるか確認します。

回復した場合も、切断したおおよその時刻と利用していたブラウザ名をサポートへお知らせください。再発条件の切り分けに役立ちます。



## サポートへ連絡する場合

次の情報があると調査を開始しやすくなります。

| 情報 | 例 |
| --- | --- |
| 発生時刻 | 2026-07-08 15:20 JST 頃 |
| 影響を受けた画面 | 管理者ポータルの組織設定 |
| 利用環境 | OS、ブラウザ、社内ネットワークかどうか |
| 再現性 | 毎回 / ときどき / 一度だけ |

画面キャプチャを送る場合は、メールアドレスや組織名などの情報を伏せてください。記録を採取できる場合は、添付前に利用者名を含む行がないことも確認します。



## 公開前メモ

認証運用チームに、プロキシ環境での確認手順と画面名の最終表記を確認中。回答後に手順を確定する。
