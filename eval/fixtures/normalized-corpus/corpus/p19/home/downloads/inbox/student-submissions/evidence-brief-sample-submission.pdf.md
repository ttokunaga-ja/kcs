# Evidence Brief: sample submission excerpt

**Claim** Public libraries should be treated as learning spaces as well as lending spaces.

**Source use** A local usage report describes how students use quiet areas after class. The report supports the claim only when the writer explains why access to a quiet place changes the learning activity being discussed.

**Reader note** The paragraph names the audience before introducing the statistic, so a reader can see why the example appears here.

1

# Peer-review prompt

Underline one sentence that links evidence to the claim. In the margin, write a question where the connection is still assumed rather than explained.

Keep the comment specific enough that the writer can find the relevant sentence again.

2

# Revision reflection

After reviewing the sample, write one sentence you would revise in your own draft and name the source relationship you need to clarify. The aim is not to copy the sample topic; it is to practice making evidence visible to a reader.
