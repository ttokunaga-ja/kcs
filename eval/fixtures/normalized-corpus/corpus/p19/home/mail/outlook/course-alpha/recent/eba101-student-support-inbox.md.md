# EBA101 student-support inbox notes



## Repeating questions

- Several students are unsure whether a source summary belongs in the opening paragraph.
- A few students can find evidence but cannot explain why it changes the claim.
- Students using screen readers need the reading guide in the same order as the class discussion.



## Reply pattern

Point students to one next action: name the claim, point to the source sentence, then explain the link in their own words. Escalate access issues to the instructional support queue rather than handling them in a grading reply.
