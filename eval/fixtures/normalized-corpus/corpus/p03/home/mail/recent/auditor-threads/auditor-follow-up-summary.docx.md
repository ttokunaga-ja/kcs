# Auditor Follow-up Summary

Access-control evidence working record | 18 July 2026

This note consolidates the questions received after the July evidence walk-through for the Harbor operations platform. It is a working summary for the Trust Engineering and GRC owners before the response bundle is released.



## Response package

The package will include the reconciliation note, the current owner register, and an explanation of the label change. The team will not send raw event exports unless the reviewer requests a narrower sample with an explicit control reference.



### Open follow-ups

- Confirm the wording used for the service-account owner field.
- Attach the current data-classification reference to the control narrative.
- Record the reviewer acknowledgement in the evidence request log after delivery.



## Questions resolved

- The reviewer can trace privileged access from request, through approval, to deprovisioning evidence.
- Read, write, and administrative operations are represented as separate event classes in the exported review set.
- The evidence owner list is maintained alongside the control narrative and does not rely on mailbox history.



### Owner confirmation

GRC owns the external response. Platform Operations owns the export provenance. Trust Engineering will retain the reconciliation procedure with the quarter-close review materials.
