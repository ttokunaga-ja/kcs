# SIEM 高リスクイベント抽出の引き継ぎ

抽出日: 2026年7月18日
引き継ぎ元: Security Operations
受け取り: Trust Engineering



## 抽出条件

- Operator Hub、Grid Console、Vendor Edge の管理者操作を対象にした。
- 未認識ネットワーク、ロール変更、緊急権限、トークン権限拡張を高リスクの候補として抽出した。
- 監査用の説明ではイベント本文をそのまま使わず、チケットで確認済みの分類と状態を参照する。



## 確認してほしい点

1. `case_reference` が空の行がないこと。
2. 緊急権限の利用に変更番号が結び付いていること。
3. Vendor Edge のサービスアカウントは、委託先の作業時間帯と突合できること。

CSV は作業用の抜粋であり、長期の保管場所ではない。再抽出が必要になった場合は、同じ条件を Security Operations のクエリ記録から再実行する。
