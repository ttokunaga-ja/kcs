# Study Alpha session plan

**Prototype:** Tidepool alpha-3.4
**Audience:** grocery planners who manage a weekly routine
**Format:** remote moderated interview



## Run of show

| Time | Activity | Notes |
| --- | --- | --- |
| 0–5 min | Welcome and consent | Establish current planning routine |
| 5–12 min | Household context | Ask about a recent grocery decision |
| 12–30 min | Prototype tasks | Start a plan, use optional staples, edit servings |
| 30–40 min | Plan-to-list reflection | Ask what the participant expects next week |
| 40–45 min | Close | Capture follow-up and thank participant |



## Facilitator prompts

- What would you expect to happen if you choose that meal?
- What feels missing before you save this plan?
- If your week changed tomorrow, where would you go first?

Keep prompts neutral. If the participant pauses, allow silence before offering help. Record observations in the session template rather than in the recruiting system.
