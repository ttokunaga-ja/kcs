# Journal de correction — lot B

Le lot B contient surtout des lettres dont les accents, les traits d'union et
les noms propres ont été affaiblis dans la copie de lecture. Les corrections
doivent rester attachées à l'image consultée; une forme plus élégante n'est
pas forcément une lecture plus fidèle.



## Vérifications effectuées

- Les fins de ligne ont été comparées lorsque la césure pouvait changer le mot.
- Les noms abrégés restent signalés comme incertains tant qu'une seconde lecture n'est pas disponible.
- La pagination de travail a été séparée de la foliation visible dans le dossier.



## File de contrôle

| Type de problème | Traitement |
|---|---|
| accent peu lisible | conserver la lecture prudente et noter le doute |
| ajout au crayon | enregistrer la position dans la marge |
| mot barré | ne pas le rétablir dans la copie courante |

La prochaine relecture portera sur les passages utiles au chapitre de
traduction, avec l'original à côté de la copie.
