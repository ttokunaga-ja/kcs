## スキャン資料参照メモ

Keller-Roth 書簡群と *Afterlives of Judgment* の作業用参照

**目的** 本メモは、受領したスキャン画像を文献調査に利用するときの参照方法を整理したものである。画像から読める情報と、後から補った書誌情報を混同しないことを優先する。

**対象** 現在の作業対象は、1990 年代前半の書簡複写、読書会の配布資料、余白に短いメモがある閲覧用コピーである。資料群は Keller-Roth 書簡群として扱うが、個々の葉の並びは確定していない箇所がある。

|  確認項目 | 記録のしかた  |
| --- | --- |
|  日付・差出地 | 画像で判読できる範囲をそのまま記し、不明部分は保留する。  |
|  書名・人名 | 画像にある表記を優先し、標準形は別欄で管理する。  |
|  余白の記号 | 線、丸印、書き込みの位置を短く説明する。  |
|  言語の切替 | ドイツ語、フランス語、英語の切替を段落単位で残す。  |

**利用上の注意** 画像は引用の出発点であり、完成した本文の根拠を単独で保証するものではない。章に用いる箇所は、対応する書簡または読書会資料との関係を確認してから採用する。

## 第 2 頁　画像と転記の照合

**照合の順序** 最初に画像の見出し、日付、余白を確認する。次に転記の改行と段落を比較し、最後に検索用に付けた補助情報を別のものとして扱う。この順序にすると、検索の都合で原資料の形を整えすぎることを避けられる。

|  画像で見つかるもの | 作業ノートへの記録  |
| --- | --- |
|  曖昧な一文字 | 読みを決めず、前後の語と位置を残す。  |
|  消えかけた下線 | 強調と断定せず、薄い線として記述する。  |
|  書名の省略形 | 省略形を保存し、候補の標準形は別記する。  |
|  ページ番号の断片 | 数字、近接する語、資料の葉をまとめて記録する。  |

**章との関係** 第 2 章では引用の回収を、第 3 章では原資料の配置と読解の差を扱う予定である。どちらの場合も、転記が滑らかであることより、どの画像から読み取ったかを追えることが重要になる。

**共有時の約束** 共同作業用のメモには、確定した読みと未確認の読みを同じ書式で並べない。未確認の箇所は簡潔な印を付け、再確認が必要な理由を一行で残す。

### 第 3 頁　次回確認のための一覧

|  作業 | 確認したいこと  |
| --- | --- |
|  書簡の順序 | 封筒と日付の対応が画像上でも一貫しているか。  |
|  読書会資料 | 追記された書名が配布資料の本文と区別できるか。  |
|  翻訳語 | 原語、仮の訳語、文脈上の働きを別々に記録できているか。  |
|  引用候補 | 本文に使う前に、資料の葉と周辺の段落を再確認したか。  |

**まとめ** Keller-Roth 書簡群のスキャンは、読書の経路を示す断片として価値がある。資料の不完全さを消さずに扱うことが、*Afterlives of Judgment* の議論に必要な慎重さにつながる。

参照用メモ。画像の保管場所や個別ファイル名は記載しない。
