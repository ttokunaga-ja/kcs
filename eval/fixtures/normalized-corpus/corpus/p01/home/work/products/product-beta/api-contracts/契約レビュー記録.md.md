# Poppy Gateway 契約レビュー記録

**July 2026 · Hummingbird Payments**



## 確認した変更

通知設定の作成と更新で、依頼の意味が混ざらないように項目の説明を整えた。配送先の用途を示す名前は利用者が指定し、実際の署名方式はサーバー側の設定から解決する。

| 領域 | レビュー結果 |
| --- | --- |
| request body | 空文字と未指定を明確に区別する |
| response body | 設定の状態を読み取り専用で返す |
| webhook header | event key と署名情報の責務を分ける |
| error body | 利用者が修正できる入力だけを説明する |



## 実装メモ

SDK の例では、受信側が payload 全体を保存しなくても検証に必要なヘッダを扱えるようにする。Orchid Ledger の記帳語彙を gateway の公開 API に持ち込まないことも確認した。
