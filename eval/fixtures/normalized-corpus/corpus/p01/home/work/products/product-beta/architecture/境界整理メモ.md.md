# Poppy Gateway の境界整理

**July 2026 · Ledger Platform**



## 現在の見取り図

Poppy Gateway は加盟店からの通知設定を受け取り、署名済みの配送処理へ渡す。配送先ごとの差異を gateway の外へ漏らさず、共通のイベント形式を維持することを優先する。

- 設定 API は加盟店ごとの配送先と有効状態を管理する
- signer は鍵の選択と署名ヘッダの組み立てを担当する
- delivery worker は送信結果を記録し、運用者が追跡できる形に整える



## 設計上の注意

配送先の URL や秘密情報は診断ログに書かない。失敗時に必要な相関情報だけを残し、詳細は安全な設定ストアから確認する。Orchid Ledger の結果イベントとは、共有する識別子とイベント種別だけで結び付ける。
