# Orchid Ledger 移行リハーサルメモ

**July 2026 · Ledger Platform**



## 進め方

Orchid Ledger 2026.07 の変更は、既存の読み取りモデルを一度に置き換えない。追加できる構造を先に用意し、隔離した環境でイベントから投影を作り直して差分を確認する。その後に利用者向けの読み取り先を切り替える。



## 確認する観点

- 新旧の表示で業務上の状態が同じ意味になること
- 作り直しの途中で運用画面が誤った説明をしないこと
- 切り戻し手順が担当者の playbook に書かれていること
- API 契約の例と公開文書が移行後の用語にそろうこと



## 注意事項

作業用の検証データを共有の資料へ貼り付けない。調査中の出力は隔離した場所で扱い、確定した手順だけを運用文書に反映する。Poppy Gateway の配送設定はこの移行の対象外として扱う。
