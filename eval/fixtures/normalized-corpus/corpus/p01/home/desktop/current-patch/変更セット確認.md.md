# 現在の変更セット確認

**July 2026 · Hummingbird Payments**



## 目的

Orchid Ledger の依頼正規化から結果通知までを、利用者向けの契約と同じ言葉で追えるようにする変更を確認した。実装の都合で内部の型名が露出しないことを重視している。



## 確認済み

- 入力検証の失敗は安定したエラー分類で返る
- 記帳命令への変換は境界で完結する
- 結果イベントには問い合わせ時に使う識別子が含まれる
- 監査画面の説明はドメインイベントの意味と一致する



## 手元で残っている作業

Poppy Gateway へ渡すイベントの説明を docs と照合する。release note の表現は API reference の最終レビュー後に更新する。テストでは具体的な検証データを本文へ残さず、期待する業務結果が分かる名前に直す。



## 提出前のチェック

変更理由を一段落で説明できるか、運用者が失敗を追跡できるか、利用者が移行手順を読めるかを順に確認してからレビューへ出す。
