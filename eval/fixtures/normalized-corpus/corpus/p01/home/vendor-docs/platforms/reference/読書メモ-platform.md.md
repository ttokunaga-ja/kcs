# プラットフォーム資料の読書メモ

**July 2026 · Ledger Platform**



## 参照したテーマ

外部プラットフォームの資料から、署名検証、鍵の更新、失敗時の診断情報の扱いを確認した。Poppy Gateway に取り込むときは、提供元の用語をそのまま公開 API に流用しない。



## ローカル設計への反映

- 署名に使う秘密情報は設定ストアで管理する
- 診断ログには配送先や機密情報を残さない
- 利用者向けのエラーは、修正可能な入力を中心に説明する
- 鍵の更新手順は operations guide から参照できるようにする



## 保留した点

提供元のサンプルには単純化された失敗処理が含まれるため、そのまま採用しない。Hummingbird Payments の監査要件に合わせて、調査に必要な相関情報だけを残す方針を別途確認する。
