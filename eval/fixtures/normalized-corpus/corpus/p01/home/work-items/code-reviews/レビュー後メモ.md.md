# 実装レビュー後のメモ

**July 2026 · Ledger Platform**



## 指摘のまとめ

Orchid Ledger の変更セットを確認し、依頼の正規化と結果イベントの組み立てが一つの関数に寄り過ぎている点を共有した。読みやすさのため、入力検証・ドメイン変換・出力整形を分ける。

- エラー分類は呼び出し元に返す情報と診断情報を混ぜない
- event payload の生成は、記帳規則を再実装しない
- テスト名は利用者の操作ではなく期待する業務結果を表す
- 設定値は helper の引数で渡し、暗黙の環境参照を避ける



## 依頼した対応

レビュー担当には、変更後の例が API reference と矛盾しないことを確認してもらう。Poppy Gateway 側の配送処理に影響する項目は、別の変更として切り出すよう依頼した。



## 次回確認

小さな差分に分けたあと、異常系のメッセージと監査画面の表示を中心に再確認する。
