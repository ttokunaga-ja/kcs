# Research library curation

このフォルダには、Harbor の判断に直接使う資料だけを置く。リンクを集めること自体は目的ではない。



## 取り込み基準

- 一次発言、観察、または再現可能な運用記録に戻れる。
- 引用できる範囲と確認日がわかる。
- 製品への示唆と、まだ不明な点を分けて書く。



## 今回の整理

「担当未定」と「前提不足」は近いが別のテーマとして残す。前者は responsibility の問題、後者は evidence の問題で、同じ UI で解けるとは限らない。

We should resist turning every note into a product requirement. A library is useful when it preserves uncertainty as well as conclusions.



## 運用メモ

原記録をコピーして編集しない。要約を更新する時は、変更理由を短く追記する。リンク切れや同意範囲が不明な資料は、参照候補から外すのではなく「再確認待ち」として扱う。
