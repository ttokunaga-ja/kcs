# Aster A1 Pilot Lot Release Brief



# Checkpoint and ownership

Quality Assurance prepares the evidence package for the pilot review. Manufacturing Engineering confirms that the work-instruction update has reached the station. Production Control keeps the affected lots identified until the review is complete.



## Evidence review

The pilot package contains the first-piece record, the tool-change confirmation, the fixture-condition check, and the lot photograph. Each item is retained with the same lot identifier so that the review team can trace a record without relying on a separate handoff.
