# V4 archived embedding-profile measurement

V4 was a completed, non-authorizing GPU experiment used to settle the local
embedding profile. Its executable Python scripts and unconsumed raw result
artifacts have been removed. The one Rust-consumed frozen profile remains in
[`results/`](results/README.md).

Current product authority lives in the frozen Rust profile constants and their
identity tests.  This directory is not an executable reproduction contract.
